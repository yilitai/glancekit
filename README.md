# glancekit

**glancekit** is a lightweight Python package providing utilities for downstream analysis of [GLANCE](https://github.com/yilitai/GLANCE) and single-cell and spatial proteomics data.

## Installation

Install the latest version from GitHub:

```bash
pip install git+https://github.com/yilitai/glancekit.git
```

To include optional utilities (such as `tqdm` progress bars):

```bash
pip install "glancekit[extras] @ git+https://github.com/yilitai/glancekit.git"
```
